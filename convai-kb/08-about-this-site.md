# About This Site / 关于本站

For visitors curious about how snowfly09.com itself is built and designed. /
面向好奇 snowfly09.com 本身如何搭建与设计的访客。

## Design direction / 设计方向
**"东方编辑 × Latent Space"** — an editorial, Eastern-typography sensibility crossed with a
machine-learning "latent space" motif. Fully bilingual (English / 中文) with light and dark themes.
/ "东方编辑 × Latent Space"——东方排版的编辑气质，叠加机器学习"潜空间"意象。全站中英双语，含明暗主题。

## Tech stack / 技术栈
- **Astro 5** (static site), **TypeScript**, **CSS Grid** layout. / 基于 Astro 5 静态构建，
  TypeScript，CSS Grid 排版。
- The hero is illuminated by ~forty-seven lines of Canvas and SVG. / Hero 由约四十七行 Canvas 与 SVG 点亮。
- Hosted on **GitHub Pages**, deployed via GitHub Actions on push to `main`. /
  托管于 GitHub Pages，push 到 `main` 经 GitHub Actions 自动部署。

## Typography & palette / 字体与配色
- **Fonts / 字体**: Fraunces, Source Serif 4, Noto Serif SC (思源宋体), JetBrains Mono.
- **Signature color / 主色**: Cinnabar / 朱砂 `#a8311e`.

## Voice widget / 语音挂件
The floating voice assistant is **ElevenLabs Conversational AI**, embedded site-wide and answering
from this knowledge base. / 右下角的浮动语音助手由 **ElevenLabs Conversational AI** 提供，全站嵌入，
依据本知识库作答。
